# pic-helper

武汉城市建筑散步的讲解者提词卡。

## 目录约定

每个地点使用一个独立文件夹，至少包含：

- 生成图片
- 讲解者提词稿
- 事实核查记录
- 图片生成提示词
- 必要的本地资料抓取

## 资料边界

GuideMe 页面标注为 AI-generated。它适合提供路线和观察角度，不作为英文楚报馆旧址的唯一史实来源。地点名称、年代和地址优先采用政府文物名录，建筑细节和报刊史采用带出处的武汉地方资料。
