# pic-helper

冷钴蓝稀疏蚀刻风格的图片制作工作区。

## 当前方向

项目不再以讲解者提示卡为主要交付物。后续图片按主题独立制作，内容、构图和尺寸由每次任务确定；视觉基线继续沿用已经验证的蚀刻版画方向。

## 视觉基线

项目统一称呼：**冷钴蓝稀疏蚀刻建筑插画**（`Cobalt-blue editorial etching illustration`）。

- 中性暖白纸张，接近 `#FCFBF7`。
- 单色冷钴蓝，接近 `#0B4FAF`。
- 低墨量、高留白、清晰轮廓和图形化概括。
- 使用稀疏点刻与少量短排线提示材质和阴影。
- 保持现代编辑插画的克制感，不做照片滤镜或高密度写实铜版画。

## 新项目最低交付物

每个主题目录至少保留生成提示词、参考图来源或事实边界记录，以及带版本号的输出图片。AI 生成图必须明确标注为风格化图像；外部参考图必须记录来源和授权边界。
