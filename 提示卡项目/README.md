# pic-helper

武汉城市建筑散步的讲解者提词卡。

## 目录约定

每个地点使用一个独立文件夹，至少包含：

- 生成图片
- 讲解者提词稿
- 事实核查记录
- 图片生成提示词
- 必要的本地资料抓取

## 当前进度

路线清单中的 16 个编号目前均已形成最终 PNG；第 17 号“喜德堂”保留“现有资料不足以确认原建筑年代与原用途”的事实边界。

项目已在本地安装 Kami Skill（`.agents/skills/kami/`），用于后续排版、渲染和内容覆盖检查。Kami 不参与原始图片生成；默认暖纸色会被项目颜色规则覆盖，避免成品继续偏黄。安装来源和版本锁定记录见 `skills-lock.json`，工作分工和试验门槛见 [图片工作流](workflow.md)。

第 29 号已完成一次 Kami 并行测试：复用已有上半部建筑图，不重新调用图片生成模型；输出为 `2520 × 5472` PNG 和单页 PDF。当前结果作为候选排版版本，v5 仍是原始基准，不自动替换。

GuideMe 页面标注为 AI-generated。它适合提供路线和观察角度，不作为英文楚报馆旧址的唯一史实来源。地点名称、年代和地址优先采用政府文物名录，建筑细节和报刊史采用带出处的武汉地方资料。
